# Simple Counter Application

A basic web application that allows users to increment, decrement, and reset a counter value. This project is perfect for understanding state management in web development.

## 🚀 Features
* **Increment:** Increase the count by 1.
* **Decrement:** Decrease the count by 1.
* **Reset:** Set the counter back to zero.
* **Responsive UI:** Works on both mobile and desktop screens.

## 🛠️ Tech Stack
* **HTML5:** For the structure of the application.
* **CSS3:** For styling and layout.
* **JavaScript:** For the counting logic and DOM manipulation.
